Playwright gives you many ways to locate elements — from CSS and XPath to user-friendly “by text” or “by role” locators.

Here’s a breakdown 👇

Locator Type	        Example	                                        Description
CSS Selector	        page.locator('input#username')	                Uses standard CSS syntax
Text	                page.getByText('Submit')	                    Finds element containing visible text
Role(Accessible Role)	page.getByRole('button', { name: 'Login' })	    Uses ARIA roles — best for accessibility & stability
Label	                page.getByLabel('Email')	                    Finds input or control associated with a label
Placeholder	            page.getByPlaceholder('Search...')	            Finds an input by its placeholder text
Alt Text	            page.getByAltText('Product Image')	            Finds images or elements by alt attribute
Title	                page.getByTitle('Close')	                    Finds element by its title attribute
Test ID	                page.getByTestId('cart-count')	                Finds elements by data-testid attribute
XPath (< recommended)	page.locator('//button[text()="Login"]')	    Works, but less readable and maintainable
Nth Element	            page.locator('button').nth(1)	                Targets the second button in the list

🧪 Examples in Action
1️⃣ Fill a form
await page.getByLabel('Email').fill('user@example.com');
await page.getByLabel('Password').fill('123456');
await page.getByRole('button', { name: 'Login' }).click();

2️⃣ Click a button by text
await page.getByText('Continue').click();

3️⃣ Use a CSS locator
await page.locator('#submit-button').click();

4️⃣ Work with multiple elements
const items = page.locator('.list-item');
await expect(items).toHaveCount(5);
